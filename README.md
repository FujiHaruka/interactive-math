# interactive-math

方程式をタイル操作で解くゲームのプロトタイプ。https://fujiharuka.github.io/interactive-math/

## 一次方程式の操作

- 移項: 項をつまんで `=` の向こうへドラッグ。越えた瞬間に符号が裏返る
- まとめる: 同じ種類の項（x どうし / 数どうし）に重ねる。`=` の向こうの項に直接重ねると移項とまとめが 1 手
- 両辺を割る: x の項をタップすると、その係数で両辺のすべての項を割る。かっこの外の数をタップすると、かっこを開かずにその数で割る
- かっこを開く: かっこの中をタップすると、外の数が中の各項に掛かる。かっこごとつまんで移項もできる
- 両辺に掛ける: 赤い分母をつまんで `=` に落とす。途中で別の分母の上を通すと、掛ける数がそれらの最小公倍数になる

## 二次方程式の操作

上の一次方程式の操作はそのまま使える。加えて:

- 平方根: `x² = 9` や `(x − 1)² = 4` のように 2 乗が 1 つだけになったら、`x²`（かっこの 2 乗）をタップ。`±` が出て盤面が「または」で 2 本に分かれ、それぞれを一次方程式として解く。√ が残る答えにも対応
- 積が 0: `(x + 2)(x − 3) = 0` の積をタップすると、`x + 2 = 0` と `x − 3 = 0` の 2 本に分かれる。`= 0` でない積をタップすると展開する
- 因数分解（面積図）: `x² + bx + c` の形にまとめた辺の `x²` をタップすると面積図が開く。● を斜めに動かすと x の帯が右と下に振り分けられ、長方形 `(x + p)(x + q)` のかどの面積 `pq` が変わる。かどが `c` になった所で離すと因数分解される。負の帯は x² の内側に食い込む赤い帯で表す
- 平方完成: 同じ面積図で帯を半分ずつにして正方形にすると、足りない（はみ出た）かどの分だけ「両辺に足す」ボタンが出る
