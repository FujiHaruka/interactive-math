# interactive-math

方程式をタイル操作で解くゲームのプロトタイプ。https://fujiharuka.github.io/interactive-math/

## 一次方程式の操作

- 移項: 項をつまんで `=` の向こうへドラッグ。越えた瞬間に符号が裏返る
- まとめる: 同じ種類の項（x どうし / 数どうし）に重ねる。`=` の向こうの項に直接重ねると移項とまとめが 1 手
- 両辺を割る: x の項が片側に 1 つだけになったら、その項をタップ
- かっこを開く: かっこをタップすると、外の数が中の各項に掛かる。かっこごとつまんで移項もできる
- 両辺に掛ける: 赤い分母をつまんで `=` に落とす。途中で別の分母の上を通すと、掛ける数がそれらの最小公倍数になる

今後の拡張候補は [docs/ideas.md](docs/ideas.md)。

ビルド不要の静的サイト。ローカルでは `python3 -m http.server` で開く（ES modules のため `file://` 不可）。
