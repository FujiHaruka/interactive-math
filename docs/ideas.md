# 拡張アイデア（未着手）

かっこ（分配法則）と分数を払う（両辺に掛ける）は実装済み。残りの候補。

## 不等式

例: `−2x + 3 < 7`

- 操作は一次方程式と同じ。負の数で割った瞬間だけ、真ん中の `<` がくるっと回って `>` になる
- 割る前に「不等号はどうなる？」と予測させる演出を入れると学習効果が高い
- クリア画面は数直線に解の範囲を塗る
- 実装コストは最小。中継ぎの寄り道に向く

## 連立方程式（2 行盤面）

例: `2x + y = 7` / `x − y = 2`

- 加減法: 行の左端のハンドルをつまんで、もう一方の行に重ねると 2 式が足される。重ねている間は和をプレビューし、0 になる項は弾けて消える
- 何倍かしてから足す: ハンドルを上下にスクラブすると ×2, ×3, ×−1 と倍率が変わり、行全体の係数がライブで書き換わる
- 代入法: `y = 7 − 2x` まで整理した行の `y` をつまみ、もう一方の式の `y` に落とすと `(7 − 2x)` のかっこ箱が入る（かっこ実装を再利用）
- 項の種類が x / y / 数 の 3 つになり、目標手数を出す総当たり探索の状態数が一気に増える。深さ制限か枝刈りが要る

## 文字式の変形（公式を解く）

例: `S = (a + b)h ÷ 2` を h について解く

- 目標の文字を光らせ、それを 1 人きりにしたらクリア
- 操作は一次方程式と同じだが、割る相手が文字になる（`÷(a+b)` の箱）
- 「方程式を解くとは何か」が一番よく見える

## 二次方程式

例: `x² + 5x + 6 = 0`

- 因数分解: 面積モデル（代数タイル）を広げ、`x²`・`x`・`1` のタイルを長方形に並べると `(x+2)(x+3)` に変わる
- 分岐: 「掛けて 0」になったら盤面が 2 レーンに割れ、`x+2=0` と `x+3=0` を並べて解く。解が 2 つあることを画面の形で体験させる
- 平方完成は「正方形の欠けを埋める」パズルにできる
- 面積モデルと盤面分岐という新しい UI 概念が 2 つ要る。一番大がかり
